Kind: feature

- **Its folder says whose it is.** Notes now tells Kehikot that the notes folder in a project is its own and holds the notes written on the project's documents with their replies, so a module that shows the project's files can say what a file there is and who writes it.

## For agents

- Notes now provides the `module.folders` service: `{ name: 'Notes', folders: [{ folder: 'notes', says: …, derived: false }] }`. Read it with `services.find('module.folders')` and `foldersOwned`.
